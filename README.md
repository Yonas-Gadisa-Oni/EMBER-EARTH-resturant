# EMBER & EARTH — Restaurant Website Demo

A premium, responsive React + Vite + Tailwind CSS restaurant website concept intended as a portfolio project.

## Requirements
- Node.js 18+ (a current LTS version is recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open the integrated terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Included
- Responsive desktop/mobile navigation
- Restaurant hero section
- Filterable sample menu
- Restaurant story and values
- Image gallery
- Location, hours and contact information section
- Reservation inquiry modal with form validation and demo confirmation state
- Responsive styling, focus states, and reduced-motion support

## Important before real client use
This is a fictional portfolio concept. It is NOT connected to a real restaurant, reservation service, database, email, or WhatsApp.
- Restaurant name, address, opening hours, menu and prices are sample content.
- Reservation form only demonstrates the frontend interaction. It does not send or store a reservation.
- Replace all demo text, prices, imagery and contact information with client-approved content.
- The images and fonts load from external Unsplash and Google Fonts URLs, so internet access is needed for those assets.
- For a real reservation workflow, connect a backend or booking provider and configure appropriate data/privacy handling.
- Check image licensing and provider terms before commercial deployment.
